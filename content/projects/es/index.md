Designed and implemented a home alarm system using **STM32F401 MCU**, integrating area and barrier sensors.

Alarm functionality implemented via buzzer with **PWM-based** sound modulation.

Enabled user interaction through a 4x4 keypad and transmitted system configurations and logs to a PC via **UART**
