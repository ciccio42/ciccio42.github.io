In this thesis the student conducted a comparative analysis of end-to-end and modular robot-learning architectures, demonstrating how the chosen design approach can substantially influence system performance. The student developed a model that achieved over 90% success on a pick-and-place task with 16 variations. The best-performing model followed a modular approach that, using human video demonstrations as input, successfully localized both the object to be picked and the target placement location despite objects configuration in the robot environment. With this architecture, the student surpassed state-of-the-art methods by more than 50%.

The student also deployed the top-performing model on a real robotic system, demonstrating its ability to reliably localize target objects and accurately execute the required manipulation tasks.
